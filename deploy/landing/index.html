VisFEM
Web visualization of FEM models.

VisFEM is a web-based tool for exploring Finite Element Method simulation results.

Below are the eleven subprojects of the DFG Priority Programme SPP2311. Select an available subproject to explore its interactive 3D visualization. More are coming soon.

A multiscale framework for acute ischemic stroke therapy based on two-phase fluid-structure interaction simulations on vascular networks Automated segmentation and Discrimination for Intracranial Aneurysms (AI4IA) Coupled analysis of active biological processes for meniscus tissue regeneration Detection limit for electromyography-based diagnostics of spontaneous muscle activity Efficient and robust coupling methods for electro-mechanic models of the human heart Evidence-based personalized rehabilitation protocols for uneventful healing with data-driven virtual twins Fluid-Structure-Interaction modeling of the heart hemodynamics using statistical shape models In-stent restenosis in coronary arteries – computational and data-driven investigations towards translational modeling Modeling, simulation and optimization of agonist-antagonist myoneural interface amputations Multi-scale algorithms and simulation methodologies for the long-term prognosis of endovascular interventions in cerebral aneurysms SimLivA II – Simulation supported Liver Assessment for donor organs II

Self-Host & Install

VisFEM is available on PyPI. Install it with pip and run the app locally or self-host it.

Docs & Source
Install via pip
pip install visfem
Run the app
visfem
Python API
from visfem.app import VisfemApp

app = VisfemApp()
app.server.start()
